# 手機版與離線測試（2026-10-12）

M1 設計 3.7、3.8。用 Playwright 驅動 Chromium，對 `tools/build-site.mjs` 建出的 `_site/`（與 GitHub Pages 上的內容相同）測試。

## 條件

| 項目 | 內容 |
|---|---|
| 瀏覽器 | Chromium（Playwright 1.56），手機模擬：375 × 740、觸控、`isMobile`、2 倍像素 |
| 世界 | 示範世界（一維運動學） |
| 未測 | 實機 iOS Safari 與 Android Chrome（這個環境沒有 WebKit 與實機）；需在上線後用真的手機補測 |

## 結果

| 項目 | 結果 |
|---|---|
| 首頁、審閱頁、班級版頁、關於頁 | 沒有橫向捲動（`scrollWidth` 與視窗同寬）；頁首按鈕自動換行 |
| 遊戲：點「帶我去」 | 角色走到建議的街燈，技能頁從下方抽屜打開，地圖縮到上半部 |
| 技能頁、題目 | KaTeX 公式正常排版；詞條可點 |
| 數值題作答 | 可作答並得到經驗值 |
| 離線 | 第一次連線後 service worker 接管頁面；切斷網路後重新整理，遊戲、首頁、框架檔下載都能使用 |
| 加入班級世界（連結） | 連線時正常（另見班級版的端對端測試）；離線情況未實測，依程式會顯示中文錯誤並建議改用檔案 |

## 發現與修正

1. **手機數字鍵盤沒有負號**：題目欄位用 `inputmode="decimal"`，iOS 的數字鍵盤沒有 `-`，負數答案（例如位移 −8 m）輸入不了。已在輸入框前加「±」按鈕切換正負號，並以模擬測試確認可答對。
2. **頁首按鈕在手機上換成兩行**：可用，但佔高度。之後若按鈕再增加，考慮收成選單。
3. **離線時加入班級世界**：用檔案加入不受影響；用連結加入需要網路。原本的錯誤訊息只提到跨網域，已改為同時提到「可能沒有網路」。
