# 示範世界生成（2026-10-12）

M1 設計 3.6（D4）：用一章開放教材生成首頁「先玩玩看」的示範世界，同時作為一次生成測試。由 Claude Code 扮演聊天型 AI，依框架 v1.1 的 4.6 逐段輸出片段，再用工作台與 `npm run validate` 驗證。

## 測試材料與條件

| 項目 | 內容 |
|---|---|
| 教材 | OpenStax《College Physics 2e》第 2 章〈Kinematics〉（CC BY 4.0） |
| 體例 | 開放教科書的單一章；8 節（§2.1–2.8）；網頁版沒有印刷頁碼 |
| 範圍 | 第 2 章全章 |
| 生成者 | Claude Code（扮演聊天型 AI） |
| 玩家設定 | 背景：高中一年級，學過一次函數與基本代數；目標：能用運動學分析日常生活中的直線運動 |
| 限制 | 這個環境無法連上 openstax.org；節次標題以網路搜尋確認，內容依模型對該章的知識改寫 |

- 四個片段依序合併：**0 錯誤、0 提醒**（第一次就通過，沒有修正請求）。
- 以 `app/review.js` 列出全部數值題的正解與干擾值，逐題人工檢查：單位一致；每個干擾值對應一個寫明的錯誤（忘了除以 2、正負號顛倒、未換算 km/h、把路程當位移等）；沒有干擾值落在 3% 以內。
- 首頁「玩示範世界」載入後直接進入遊戲；審閱頁與班級版匯出可正常使用（開放授權，班級版不移除任何內容）。
- `test/demo-world.test.mjs` 把關：世界檔通過 schema 與全部檢查，且等於四個片段的合併結果。

## 發現

1. **沒有印刷頁碼的文件**：網頁版開放教材沒有頁碼，`pages` 與 `ref.page` 都省略；班級版的「內容見原書」只能指向節次。框架 7.1 沒有說明沒有頁碼時怎麼辦，本次的做法（只寫節次）可行，暫不改框架。
2. **例題編號不確定時省略**：無法逐字核對原書，`examples`、`practiceRefs` 一律省略，避免捏造（框架 7.1）。真正使用時 AI 會讀到原文，不會有這個問題。
3. **道館成就**：3.4 沒有道館的成就等級；本次把道館成就列為銅（3.4 允許少量特殊成就）。可觀察其他 AI 的做法再決定是否寫進框架。
4. **框架排版錯誤**：7.5 的 `1.602 \times 10^{-19}` 中 `\t` 被存成了 Tab 字元（v1.0 就有），已在 v1.1 修正。
