| 項目 | 決定 |
|---|---|
| 氛圍 | 隨進度由暗轉亮：一開始是黃昏的城市，點亮的技能越多，街區越亮 |

## 2. 技能樹

### 2.1 版面（`engine/skill-tree-model.js`，純函式，可在 Node 測試）

- 起點在下方中央，往上展開成約 187° 的扇形。
- **扇形分區**：先依階級分成幾大區（區與區之間留較寬的間隔），區內再依章分成小扇形；每章分到的角度與它最寬那一層的技能數成正比。世界只有一兩章時，整個扇形收窄，不攤滿半圓。
- **一圈一層**：技能所在的圈 = 它在本章內的先修深度（沒有本章先修的在第 0 圈）。
- **同一圈的排序**：依先修技能的平均角度排序，讓連線盡量短、不交錯。
- **最內圈半徑**自動放大到每一章的每一層都排得下（節點間距至少 54 單位）。
- **連線**：本章內的先修畫成「從先修往外 → 沿弧線 → 往外到技能」的折線，轉折處畫小圓點。起點有一條主幹接到各章第 0 圈。跨章的先修平常不畫；選取技能時，才用虛線畫出它跨章的先修與後續。
- 輸入只有世界檔（技能、技能群、先修、知識類型、階級），不需要 AI 提供任何座標；任何書都能自動排版。

### 2.2 節點

| 狀態 | 樣子（不只靠顏色） |
|---|---|
| 已點亮 | 實心暖色圓、光暈；外圈依 `maxLevel` 分格，已達的等級亮起 |
| 可以學 | 深色圓、暖色外框、右上「！」 |
| 未解鎖 | 深色圓、灰色外框、右上鎖頭 |
| 待複習 | 已點亮加上緩慢旋轉的虛線外圈、右上時鐘（引擎 D 有複習排程後才會出現） |

- 圓圈中央是知識類型的小圖示（事實、概念、程序、原理、判斷）；名稱寫在下方。技能多時，縮小到一定比例以下就隱藏名稱。
- 狀態沿用 `engine/progress.js`：`lampState` 與 `skillLevel`。

### 2.3 畫面與操作（`engine/skill-tree.js`）

- 遊戲畫面新增「技能樹」按鈕；全螢幕疊在地圖上，SVG 繪製。
- 拖曳移動、滾輪與雙指縮放、放大／縮小／全部顯示按鈕；開啟時自動縮放到全部可見。
- 點技能：桌機在左上、手機在下方抽屜顯示說明卡（名稱、章、知識類型、狀態、等級、先修），按鈕「開啟技能頁」「帶我去」（關閉技能樹並走到地圖上的街燈）。
- 鍵盤可操作：每個節點可聚焦，Enter 開啟說明卡；Esc 關閉技能樹。
- 背景的暖光強度跟著點亮比例增加。

## 3. 路網地圖

### 3.1 版面（`engine/layout.js`）

- 街區（章）改成**蛇形排列**：每列最多 `min(5, ceil(√章數))` 個街區，一列往右、下一列往左，列與列之間用道路銜接。20 章是 5 × 4，不再是 782 格長的一列。
- 街區之間是道路與草叢（之後的遭遇區）；階級提升處沿用懸崖與階梯，並在旁邊放「晉階關卡」石門。
- 道路盡頭放最終 Boss 的建築（C2 才能進入）。
- 一個街區只有一章時，地圖維持現在的單一街區樣子。
- 街區內部的配置（街燈、看板、委託人、道館）不變。

### 3.2 地景（`engine/tiles.js`）

依該章最多的知識類型決定街區的地面、屋頂與邊框色：

| 知識類型 | 地景 |
|---|---|
| 概念 | 公園區（綠地、樹） |
| 原理 | 港口區（水邊、藍色調） |
| 程序 | 工坊區（磚、暖棕色） |
| 事實 | 書街（石板、灰色調） |
| 判斷 | 廣場區（石板、紫色調） |

全部用程式繪製；同一個世界每次都產生相同的地圖（以世界 ID 為亂數種子）。

## 4. 由暗轉亮

- **地圖**：整張地圖疊一層夜色，濃度隨全世界的點亮比例降低（0% 時為黃昏，100% 時接近白天）。已點亮的街燈周圍挖出暖色光圈，街區的窗戶隨該章點亮比例亮起。
- **技能樹**：背景暖光與起點的百分比，跟著點亮比例增強。
- 尊重「減少動態效果」設定：不閃爍、不旋轉，只保留亮度變化。

## 5. 共用色彩（網站頁面）

- 新增 `engine/theme.css`：街燈暖色、夜色、線條、狀態色等 token，`app/` 與 `engine/` 都引用。
- 網站頁首加上街燈圖示與標題字樣；按鈕、連結、狀態標籤改用同一組 token。淺色與深色主題都要可讀。
- 內文字型不變；不打包額外字型（標題字樣用系統字型加字距處理）。

## 6. 不在本段

Boss 戰畫面與成就徽章（C2）、間隔複習與遭遇（引擎 D）、世界總覽（多世界）、委託美術素材。

## 7. 相容性

- 世界檔、進度、備份格式都不變；技能樹與地圖的座標每次由世界檔算出，不存檔。
- 地圖改版後，舊的角色位置可能落在不同地方：`map.js` 已在位置不可走時改用出生點，可接受。
- 不調整 schema 與框架。

## 8. 測試與驗收

- `test/skill-tree-model.test.mjs`：每個技能都有座標；同一圈相鄰節點的距離至少 54；同一章的節點都在該章扇形內；階級區依序排列；相同世界輸出相同。
- `test/layout.test.mjs`（擴充）：20 章世界的地圖寬高比不超過 3:1；所有街燈從出生點都走得到；一章世界的地圖與現在相同大小級距。
- 示範世界與 20 章規模世界：技能樹開啟 < 300 ms，地圖維持約 60 fps（Chromium 量測，寫入 `docs/test-log/`）。
- 手機寬度（375 px）：技能樹可縮放、點選，說明卡不遮住整個畫面。
